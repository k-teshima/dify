# エージェントフレームワーク

## 1. 機能概要

エージェントフレームワークは、LLM を利用した自律型エージェントを構築・実行するための柔軟な仕組みを提供します。エージェントは組み込みツールや API ベースのツール、ワークフローなどを呼び出し、Chain-of-Thought や Function Calling といった推論戦略に沿ってタスクを実行できます。

## 2. アーキテクチャ

エージェントは `AgentRunner` を中心としたループで動作し、LLM モデルやツール群と連携しながら最終的な回答を生成します。ツールの呼び出し結果や思考過程は履歴として記録され、必要に応じてプロンプトに組み込まれます。

## 3. 主なモジュール

- `api/core/agent/` : エージェントランナーや戦略を提供
- `api/core/tools/tool_manager.py` : ツールの発見と実行を管理
- `api/core/agent/prompt/template.py` : CoT 用のプロンプトテンプレート
- `api/core/agent/output_parser/` : LLM 出力の解析

## 4. データフロー概要

1. ユーザーの入力を受け取る
2. プロンプトを構築し LLM を呼び出す
3. LLM の出力からツール使用の要否を判定
4. ツールを実行し結果を取得
5. 必要に応じて再度 LLM を呼び出し最終回答を生成
6. エージェントの思考過程や使用トークンはログとして保存

## 5. 拡張ポイント

- 新しいエージェント戦略の追加
- 独自ツールの実装（組み込みツール、API ツール、ワークフロー利用、プラグインツール）
- プロンプトテンプレートやツールパラメータ処理のカスタマイズ
