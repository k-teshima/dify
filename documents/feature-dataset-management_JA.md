# データセット管理

## 1. 機能概要

ファイルアップロードや Notion 連携、Web クロールなど多様なデータソースから知識データセットを作成・管理します。抽出、クリーンアップ、分割、埋め込みやキーワード索引を行い、RAG 用に利用可能なデータベースを構築します。

## 2. 処理パイプライン

1. ソースからデータを取得
2. 解析・前処理を実施
3. セグメント化してベクトル化またはキーワード化
4. インデックスを作成し検索に利用

## 3. 連携と利用

- アプリケーションからデータセットを参照し、質問応答に活用
- データソースの更新や再インデックスもサポート

## 4. 拡張ポイント

- 新しいデータソースの追加
- 埋め込みモデルや検索方式のカスタマイズ
