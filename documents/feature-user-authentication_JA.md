# ユーザー認証

## 1. 機能概要

ユーザーのログインや登録、パスワード管理、セッション制御、API キー管理を行います。メールアドレス・パスワードによる認証、メールコード認証、Google や GitHub など外部プロバイダ経由の OAuth 認証に対応します。チャットボットなどの Web アプリでは、認証済みユーザー向けと匿名アクセス向けのトークン方式を提供し、データソース用には API キー認証も利用できます。

## 2. アーキテクチャ

API ゲートウェイを通じてコンソール、Web アプリ、データソース向けの認証エンドポイントを提供し、各種認証プロバイダやセッションストアと連携してユーザー情報を管理します。

## 3. データフロー

1. ユーザーが認証情報を送信
2. 認証方式に応じて認証プロバイダを呼び出し、トークンやセッションを発行
3. アプリケーションは発行されたトークンを用いて API にアクセス

## 4. 拡張ポイント

- 新しい OAuth プロバイダの追加
- 多要素認証やセキュリティ設定の強化
