# プラグインシステム

## 1. 機能概要

プラットフォームに外部のツールやサービス、モデルを組み込むための仕組みです。プラグインはツールとしてエージェントやワークフローから利用できるほか、新しいモデルプロバイダや各種拡張を提供します。専用のプラグインデーモンがインストールや依存関係、実行を管理するため、コアコードを変更せずに機能拡張が可能です。

## 2. アーキテクチャ

ユーザーはコンソールや API を通じてプラグインを追加・管理します。プラグインデーモンはパッケージとマニフェストを保持し、ツール呼び出し時にはプラグインランタイムで実際の処理を行います。

## 3. 利用フロー

1. プラグインをインストール
2. エージェントやワークフローがプラグインツールを要求
3. プラグインデーモンがツールロジックを実行し結果を返す

## 4. 拡張ポイント

- 新しいプラグインタイプの追加
- 権限管理やセキュリティ設定の強化
