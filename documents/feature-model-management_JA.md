# モデル管理

## 1. 機能概要

LLM や埋め込みモデル、リランキング、音声認識、モデレーション、音声合成など、複数プロバイダのモデルを一元的に管理します。認証情報の設定、モデルごとのパラメータ管理、利用枠の制御、ワークスペース単位での有効化・無効化などを行います。

## 2. アーキテクチャ

モデルの定義はデータベースに登録され、アプリケーションは必要に応じてモデルインスタンスを取得して利用します。API キーやエンドポイント設定は安全に管理されます。

## 3. 主な機能

- モデルプロバイダの資格情報登録
- 利用するモデルの選択とパラメータ設定
- トークン使用量の計測とクォータ管理
- ワークスペースごとのモデル利用制御

## 4. 拡張ポイント

- 新しいモデルプロバイダの追加
- 料金計測や監視機能との連携
