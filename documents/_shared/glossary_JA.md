# 用語集

## API

アプリケーションプログラミングインターフェース。異なるソフトウェア同士が通信するための規約やプロトコルの集合。

## コンソール

一般的にはテキストベースのユーザーインターフェースで、コンピュータシステムやソフトウェアアプリケーションと対話するために使用されるもの。

## コア

システムやアプリケーションの中心的で最も重要な部分。基本的な機能を提供する。

## サービス

他のコンポーネントやユーザーに対して特定の処理や機能を提供するソフトウェアコンポーネント。

## Web

World Wide Web に関連するもので、主に Web アプリケーションやウェブサイト、またはウェブベースの技術を指す。

## LLM

Large Language Model の略。大量のテキストデータで学習され、人間の言語を理解・生成・操作できる AI モデル。

## エージェント

周囲の状況を知覚し、意思決定し、特定の目標を達成するために行動する自律的なソフトウェア。

## ワークフロー

一連のタスクやステップで構成されるプロセス。多くの場合自動化され、処理の流れを定義する。

## データセット

機械学習モデルの学習や分析などに利用される、構造化された関連データの集合。

## プラグイン

既存のソフトウェアアプリケーションに特定の機能を追加するソフトウェアコンポーネント。

## テナント

マルチテナントアーキテクチャにおいて、ソフトウェアアプリケーションのインスタンスに共通のアクセス権を持つユーザーグループ。

## 埋め込み（Embedding）

機械学習において、テキストや画像などのデータを数値ベクトルとして低次元空間に表現し、意味的な関係性を捉えたもの。

## RAG

Retrieval Augmented Generation の略。知識ベースから関連情報を取得する仕組みと、生成モデル（LLM など）を組み合わせ、より正確で文脈に沿った出力を生成する AI フレームワーク。
