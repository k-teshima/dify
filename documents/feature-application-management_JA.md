# アプリケーション管理

## 1. 機能概要

アプリケーション管理機能では、さまざまな AI アプリを作成・設定・デプロイし、状態を監視できます。チャットボットや補完系アプリ、ワークフローオーケストレーターなど複数のモードをサポートし、モデル設定やプロンプトテンプレート、データセット連携などを柔軟に構成可能です。

## 2. アーキテクチャ

コンソールおよび API を通じてアプリのライフサイクルを管理します。設定情報はデータベースに保存され、実行時にはモデルやデータセット、エージェント設定などが組み合わされて動作します。

## 3. データフロー

1. ユーザーがコンソールまたは API でアプリを作成
2. モデルやプロンプト、ツール、データセットを設定
3. デプロイ後、アプリケーションは実行環境でリクエストを受け付け
4. 実行ログや指標を取得しながら改善を行う

## 4. 拡張ポイント

- 新しいアプリケーションタイプの追加
- 設定項目のカスタマイズ
- 外部システムとの統合
